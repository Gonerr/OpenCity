# Открой город

**«Открой город»** — командный учебный сайт-гид по Санкт-Петербургу.

Проект помогает познакомиться с достопримечательностями города, посмотреть подборку интересных мест и выбрать тематический маршрут. В репозитории находится первая статическая версия интерфейса, опубликованная на GitHub Pages.

[Открыть сайт](https://gonerr.github.io/OpenCity/)

> Проект является контентным и интерфейсным прототипом туристического сервиса. Отдельная React-версия развивается в репозитории [openCity_react](https://github.com/Gonerr/openCity_react).

---

## Цель проекта

Сайт создавался для решения нескольких пользовательских задач:

- собрать информацию о местах Санкт-Петербурга в одном интерфейсе;
- упростить подготовку короткой туристической поездки;
- показать не только известные достопримечательности, но и необычные локации;
- предложить тематические маршруты;
- дать пользователю визуальное представление о городе до поездки.

---

## Основные разделы

### Главная страница

- презентация идеи проекта;
- тематические категории мест;
- переход к маршрутам;
- преимущества сервиса;
- адаптивная навигация.

### Маршруты

В проект добавлены карточки тематических прогулок, включая:

- маршрут по мостам Санкт-Петербурга;
- подборку необычных дворов;
- краткие описания и визуальные материалы.

### Галерея

Галерея содержит подборку городских мест:

- Ботанический сад;
- Ростральные колонны;
- Витебский вокзал;
- особняк Клейнмихель;
- Атланты и другие локации.

Для карточек используются фотографии, названия и адреса.

### О проекте

Раздел описывает этапы создания продукта:

1. формирование идеи;
2. разработка дизайна;
3. создание интерфейса;
4. публикация сайта.

### Команда

Отдельная страница содержит информацию об участниках, ролях и личном опыте командной разработки.

## Локальный запуск

Склонируйте репозиторий:

```bash
git clone https://github.com/Gonerr/OpenCity.git
cd OpenCity
```

Откройте `index.html` в браузере или запустите статический сервер:

```bash
npx serve .
```

## Текущее состояние и развитие

Статическая версия содержит основные страницы и демонстрационный контент, но не является полноценным туристическим сервисом.

Возможные направления развития:

- добавить подробные страницы локаций;
- сделать маршруты интерактивными;
- подключить карту;
- добавить фильтрацию мест по тематике;
- реализовать поиск;
- вынести контент в JSON или CMS;
- улучшить семантическую разметку и доступность;
- убрать демонстрационные и незаполненные блоки;
- продолжить перенос интерфейса на React.
